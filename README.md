# IndexBudget

Подбор дополнительных индексов PostgreSQL для нескольких сценариев нагрузки под заданные бюджеты.

Проект находится на этапе проектирования MVP. Актуальная [спецификация v0.2](IndexBudget-spec-v0.2.md) описывает CLI, формат входа, ограничения и критерии приёмки; готовая реализация пока не заявляется.

Порядок работы для агентов — в [AGENTS.md](AGENTS.md). В [ai/](ai/README.md) описаны целевая архитектура, контракты, соглашения разработки и [ревью PR без запуска тестов](ai/review.md). Владельцы, зависимости и контрольные точки — в [общем плане #2](https://github.com/ITMO-DevDays-2026-IndexBudget/IndexBudget/issues/2).
