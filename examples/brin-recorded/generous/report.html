Как получена оценка и где её границы

Write proxy — условная модель по числу колонок: одинаковое число колонок B-tree и BRIN не означает одинаковую реальную цену записи.

Baseline — оценка с существующими индексами. Новые наборы оценены целиком через HypoPG, без физического построения. Поиск ограничен и не гарантирует лучший возможный набор.

Ограничения методики

Вывод относится только к переданным SQL и параметрам. Время запросов и записи, фактический размер индексов и конкуренция запросов не измерены. Planner cost не обещает SLA.

Как оцениваются место и запись

Место: для каждого индекса учитывается округлённая вверх оценка HypoPG с заданным запасом, затем размеры складываются. KiB = 1 024 байта; MiB = 1 048 576 байт.

Запись — условная модель, не число операций и не измеренное замедление. Модель одного индекса: (INSERT + UPDATE + DELETE строк/ч) × (число ключей + число INCLUDE-колонок). Расходы индексов суммируются.

Модель не измеряет WAL, I/O, HOT, ширину ключей, разрастание индексов или отложенную очистку после DELETE.
