  установленного дистрибутива запускаются с JDK 25. Это уже собранный локальный CLI,
  не результат новой чистой сборки.
- `analyze-series --help` и `--version` также выполнены с JDK 25.
- Локальные Markdown-ссылки изменённых документов проверены на существование файлов;
  приведённые JSON-примеры разбираются как JSON. Это не проверка удалённых URL или
  всех семантических ограничений входа.
  Проверено 145 ссылок и 11 связанных JSON-примеров.
- Быстрый запуск сопоставлен с frontend/README.md, Compose и сервером: собственный
  проект indexbudget-frontend, HTTP 8090, PostgreSQL loopback 55433, фиксированные
  датасеты, существующий CLI. Демо не требует npm или установки Python-пакетов.

## Не завершено: чистая установка и запуск браузера

Попытка сборки из чистого экспорта main с JDK 25 и `--offline` остановилась до сборки:
доступ к lock-файлу Gradle distribution в пользовательском кэше запрещён средой выполнения.
Docker API также возвращает permission denied на локальном socket. Поэтому новая
сборка/загрузка зависимостей, Compose, новый анализ и открытие отчёта из браузера в
этой среде **не проверены**. Наличие старых CI/benchmark результатов не заменяет
повторение быстрого запуска из чистого окружения. Этот критерий E2 остаётся открытым.

Для завершения на машине с JDK 25, Python 3.10+, Docker Engine/Compose и интернетом:

1. В новом каталоге выполните блок быстрого запуска из корневого README. Используйте
   новые output-каталоги и свободные порты 8090/55433; не останавливайте чужие сервисы.
2. Откройте 127.0.0.1:8090, выберите «Чтение и запись», выполните одиночный анализ.
   Проверьте report.html/report.json/indexes.sql, реальный статус и причины partial,
   если поиск остановился по лимиту. Не требуйте совпадения конкретных индексов/cost.
3. Запустите storage-серию и write-серию из 3–5 разных значений. Проверьте сводку,
   локальные ссылки точек и сохранённое происхождение записи.
4. Для observed примера импортируйте готовый workload с корректным origin через
   форму по frontend/README.md. Собственные снимки требуют подготовленного
   pg_stat_statements и прав; быстрый запуск не включает расширение автоматически.
5. Сохраните SHA, версии, команды и фактические результаты; после этого дополните
   этот документ. Остановите сервер Ctrl+C и только собственный frontend Compose.

Первая установка требует доступа к Gradle distributions, Plugin Portal, Maven Central,
Docker Hub, GitHub и apt-репозиториям образа. Для корпоративного VPN может потребоваться
доверенный CA в JVM или сборка вне VPN; отключение TLS-проверок не является инструкцией
проекта. Windows launcher — `.bat`; примеры shell рассчитаны на macOS/Linux.
