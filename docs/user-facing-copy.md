# Тексты интерфейса и отчётов

Редактура отделена от изменения поведения. Форма и отчёты обращаются к пользователю
на «ты». CLI help остаётся на английском. Технические коды, имена JSON-полей,
параметры команд и единицы измерения сохраняются.

## Где находятся тексты

| Поверхность | Файлы |
|---|---|
| Форма, подсказки, тур, сообщения валидации | frontend/static/index.html, frontend/static/app.js |
| Ошибки HTTP, архив и сохранённые результаты серии | frontend/server.py |
| Описания датасетов и SQL-примеров | frontend/templates/*.json, demo/scenarios/catalog.json |
| Help и сообщения команд | src/main/kotlin/ru/itmo/indexbudget/cli/ |
| Одиночный отчёт, серия, общие каталоги и профиль записи | src/main/kotlin/ru/itmo/indexbudget/report/ |
| Копирование и подписи при переключении вариантов | src/main/resources/report/report.js, series.js |

Простые подписи вроде «Нет данных», названия команд и точные формулы оставлены.
В этой правке нет массового переименования кодов ошибок или исторических артефактов.

## Что изменилось

- Вступление демо объясняет, что нужно указать и какой результат получится.
- Тур ведёт от датасета к запросам, частотам, бюджетам и отчёту.
- В основных пояснениях «workload» заменён на SQL и частоты, «shortlist» на список
  или пул кандидатов. В CLI и технических подробностях сохранены имена контрактов.
- Наблюдаемый профиль описан через источник, окно и изменённые строки/час.
  Его данные не выдаются за наблюдение текущего запуска демо.
- Режимы подписаны «бюджет 30/90/300 с». Подготовка БД и сохранение файлов могут
  увеличить время запуска; подпись не обещает завершения ровно за этот срок.
- Описания BRIN/hash предлагают сравнить бюджеты, не обещая конкретную рекомендацию.
- Сообщения ошибок подсказывают следующий шаг; сообщения о неизвестных данных
  сохраняют различие между отсутствием, нулём и неполным результатом.

Planner cost по-прежнему означает оценку PostgreSQL. Write proxy остаётся условной
моделью обслуживания индексов. Историческое время, измеренные latency/WAL/TPS и
эти оценки различаются. Все ограничения DML, HypoPG, прав и бюджетов сохраняются.

## Проверки этой правки

Выполнены 30 JS-тестов формы, проверка report-controls и 36 Python-тестов,
не требующих открытия HTTP-сокета. Дополнительно проверено, что Kotlin-код за
пределами литералов не изменился, Python AST отличается только текстом, а JSON
датасетов отличается только description/purpose/syntax_hint.

Полный Python-прогон дал 40 успешных проверок и шесть ошибок окружения: пять
HTTP-тестов не смогли открыть сокет, ещё один тест запуска отдельного сервера
не получил адрес. Эти проверки не отключались. JVM-тесты не начали выполняться:
среда запрещает запись lock-файла в пользовательский Gradle-кэш. Браузерная
проверка новой версии страниц и отчётов не выполнена.

Проверка на машине с JDK 25 и доступным Docker:

```sh
./gradlew --no-daemon build installDist reportPreview
python3 -m unittest discover -s frontend/tests -v
node --test frontend/tests/test_app.js
bash demo/check-report-ui.sh
```

Для Python нужен 3.10+. Для браузерной проверки используй зависимости,
описанные в demo/check-report-ui.sh. Старые сохранённые HTML-отчёты отражают
тексты того запуска; для просмотра новой версии создай новый отчёт.
